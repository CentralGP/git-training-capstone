# Team handbook repo (capstone)

This is the final practice exercise. It is a small repository about how a team handles requests: a
team reference, a process document, a settings file and one Claude skill.

**All details in this repository are made up.** The people, forms and times are invented.

## Ground rules

1. Work only in your own copy of this repository.
2. Never put real passwords, keys or business data in any file here.
3. Check everything the AI produces. Claude can be confidently wrong, so every claim goes in
   `VERIFICATION-LOG.md` and is checked against the files before you act on it.
